# 权衡 The Trade-off

一个"平衡利润与使命"的经营决策小游戏：你是一家正准备 IPO 的制造厂「恒捷智造」的 CEO，
要在四年里于 **短期订单、环保减排、员工福祉、智能化改造** 之间分配有限资源，
同时不让投资者或利益相关者任何一方的支持度归零。

玩法致敬英国《金融时报》2019 年的新闻游戏 [The Trade-off](https://ig.ft.com/esg-purpose-profit-game/)，
**所有文案为原创本土化内容**（制造业 + AI 设定），数值与事件机制为重新设计实现。

## 特性

- 🎮 完整 4 回合流程：分配资源 → 逐领域反馈 → 触发型事件 → 两难抉择 → 多结局
- 🌏 **一键切换中文 / English**：全部文案按语言外置（`src/content/zh.ts` / `en.ts`），
  新增语言只需加一个内容文件并在注册表登记一行，无需改动任何组件
- ⚙️ 内容与逻辑分离：数值、触发条件、文案全部是数据配置（`src/content/`），
  换一个行业设定 = 换一套内容文件
- ✅ 55 项逻辑断言测试（完整模拟对局逐项核对计分）+ 双语 SSR 冒烟测试

## 技术栈

React 18 + TypeScript + Vite + Tailwind CSS。纯前端，无后端依赖。

## 本地运行

```bash
npm install
npm run dev        # 开发服务器
npm test           # 逻辑测试 + SSR 冒烟测试
npm run build      # 产物输出到 dist/
```

## 目录结构

```
src/
  content/      # 全部文案与数值配置（i18n 内容契约 + 中文/英文内容）
  game/         # 纯逻辑状态机（回合推进、计分、事件触发、结局判定）
  i18n/         # 语言上下文（localStorage 持久化 + 浏览器语言探测）
  components/   # UI 组件（零硬编码文案，全部从当前语言内容取词）
test/           # 无头逻辑测试与 SSR 冒烟测试
```

## 玩法设计说明

- 每回合 10 点资源（第 2 回合衰退期 8 点），分配到 4 个领域，每领域 0–3 级
- 双方支持度初始 5，任一归零立即出局；结局按 0–3 / 3.5–6.5 / 7+ 分档组合
- 12 条触发型事件根据历年分配模式触发（如"连续两年员工投入 ≥2 → 最佳雇主"）
- 3 个两难抉择对应三个本土议题：AI 自动化与岗位、衰退期员工福利、双碳承诺
